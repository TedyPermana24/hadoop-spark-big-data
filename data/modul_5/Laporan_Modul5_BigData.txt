1	Pendahuluan
Modul ini membahas paradigma pemrograman komputasi terdistribusi MapReduce pada ekosistem Big Data Apache Hadoop. Pembahasan mencakup prinsip kerja model MapReduce yang terdiri dari fungsi Map, fase Shuffle & Sort, dan fungsi Reduce, pengaliran pasangan kunci-nilai (key-value pairs), optimasi efisiensi transfer data menggunakan Combiner (mini-reducer lokal), serta perutean partisi ke Reducer melalui mekanisme Partitioner. Modul ini menguji implementasi program MapReduce baik menggunakan bahasa Java melalui Native MapReduce API maupun bahasa Python melalui utility Hadoop Streaming. Penerapan praktis mencakup tiga kelas permasalahan fundamental Big Data: penghitungan frekuensi kata (Word Count), analisis berkas log sistem (Log Analysis), dan penggabungan dua himpunan data terpisah (Reduce-Side Join). Selanjutnya, seluruh konsep tersebut diimplementasikan ke dalam studi kasus analitik kesehatan skala besar pada 10.000 data rekam medis elektronik (EHR) terdistribusi di HDFS yang hasilnya diintegrasikan secara langsung ke antarmuka web dashboard klinisi pada Serving Layer.

Pada fase Shuffle & Sort, keluaran Mapper dikumpulkan, dipartisi, dikirim melalui jaringan, dan diurutkan berdasarkan kunci sebelum diterima Reducer. Hadoop menggunakan HashPartitioner secara default dengan rumus partition = (key.hashCode() & Integer.MAX_VALUE) % numReduceTasks. Mekanisme ini memastikan seluruh pasangan dengan kunci yang sama dikirim ke Reducer yang sama. Keluaran Mapper ditampung pada buffer memori, diurutkan secara lokal, lalu ditulis sementara ke disk ketika ambang buffer tercapai. Jika Combiner diaktifkan, agregasi lokal dilakukan sebelum data ditransfer. Reducer kemudian menggabungkan data terurut sebelum menjalankan fungsi reduce(). Partitioner khusus dapat diterapkan untuk mengatasi ketimpangan distribusi data (data skew).

3	Studi Kasus Kesehatan (Health Informatics Case Study)
Rumah sakit mengelola repositori data pasien berskala besar yang mencakup rekam medis elektronik (Electronic Health Records / EHR). Untuk mendukung analitik klinis secara terdistribusi, diterapkan HDFS sebagai repositori data historis, Hadoop MapReduce sebagai mesin komputasi paralel, dan Serving Layer Dashboard sebagai antarmuka penyajian hasil analitik bagi dokter serta manajemen rumah sakit. Dataset full_dataset_ehr.csv berisi 10.000 riwayat pasien dengan 20 atribut, antara lain patient_id, usia, jenis kelamin, wilayah, diagnosis, tingkat keparahan, tekanan darah sistolik dan diastolik, detak jantung, kolesterol, BMI, serta status adverse_outcome. Dataset diunggah ke HDFS pada direktori /hospital/mapreduce/full_dataset_ehr.csv.

[Placeholder Gambar 14. Dataset EHR pada direktori HDFS]

Job 1 menganalisis jumlah pasien berisiko tinggi pada setiap wilayah. Pasien dikategorikan berisiko tinggi apabila memiliki tekanan darah sistolik >= 140 mmHg, kolesterol >= 240 mg/dL, atau usia >= 60 tahun. Mapper memvalidasi kondisi klinis dan menghasilkan nama wilayah dengan nilai 1, Combiner melakukan agregasi lokal, sedangkan Reducer menjumlahkan pasien berisiko tinggi per wilayah. Hasil pengujian menunjukkan 6.508 dari 10.000 pasien (65,08%) masuk kategori risiko tinggi. Wilayah North mencatat 1.341 pasien, South 1.314 pasien, Central 1.304 pasien, West 1.298 pasien, dan East 1.251 pasien.

Implementasi arsitektur komputasi terdistribusi MapReduce pada data kesehatan skala besar ini memberikan manfaat langsung bagi dua pemangku kepentingan:
1.	Rumah Sakit dan Tim Data Engineer
Membuktikan keandalan ekosistem Apache Hadoop dalam memproses komputasi analitik terdistribusi pada 10.000 rekam medis elektronik (EHR) secara paralel tanpa kendala memori, mengoptimalkan bandwidth kluster melalui penerapan Combiner yang memangkas volume pertukaran data intermediate sebelum fase Shuffle & Sort, menjamin keandalan distribusi data menggunakan HashPartitioner, serta menyajikan pipeline otomatis dari penyimpanan blok HDFS hingga ke antarmuka web Serving Dashboard.
2.	Dokter dan Peneliti Medis
Memperoleh bukti klinis empiris untuk memetakan 6.508 pasien berisiko tinggi (65,08% dari total populasi) dengan konsentrasi prioritas di wilayah North (1.341 pasien) dan South (1.314 pasien), mengidentifikasi penyakit dengan adverse outcome rate tertinggi yaitu Coronary Artery Disease (42,56%) dan Chronic Kidney Disease (41,97%), serta memetakan profil tekanan darah sistolik kritis pada kategori Severe (>164 mmHg) untuk percepatan tindakan preventif dan alokasi ranjang perawatan intensif (ICU).
